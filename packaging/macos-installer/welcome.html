Install or update Auto Subtitle Plus

This installer places Auto Subtitle Plus in Applications. If it is already there, the app bundle is replaced by this version. Finish any running job and quit the app before continuing.

Your saved settings, queue, downloaded models and exported files stay in their existing locations. You do not need to uninstall first.

Requires Apple Silicon, macOS 26 or later, and a separate installation of FFmpeg. Python and processing libraries are included. Models download when selected in the app.

Updates are manual: download a newer installer and run it. The app does not check for updates or install them in the background.
