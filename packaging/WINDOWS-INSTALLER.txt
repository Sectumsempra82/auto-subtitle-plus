Auto Subtitle Plus - Windows setup and manual updates

This is the one Windows download: a single EXE for both the desktop and the
command-line editions. It asks how to set it up, then a destination folder.

- Install: adds a Start Menu entry, an optional desktop shortcut and an
  uninstaller. Program Files is the suggested folder.
- Portable: only copies the application files into the folder you choose
  (a USB drive or any folder you manage yourself); nothing else on this
  computer changes and no uninstaller is registered.

Because the suggested folder is inside Program Files, Setup always asks
Windows to run elevated (one UAC prompt) even for Portable, which still only
copies files into the folder you picked. First launch afterwards prepares
verified app-local dependencies. Setup asks for Auto, CPU or NVIDIA CUDA.
Auto detects a working NVIDIA GPU and prepares CUDA; otherwise it uses CPU.
CUDA dependencies download about 4.3 GiB. Models download separately.
The selected hardware also applies when updating an existing installation,
replacing a stale runtime selection while preserving models and other data.
New Install-mode copies keep dependencies and user data in a private folder
under your LocalAppData, so first launch can write without administrator
privileges. Existing sibling data folders remain in use. Portable copies
keep data beside the application. AUTO_SUBTITLE_PLUS_DATA_DIR overrides both.

Finish running jobs and close both editions before updating. Run the newer
EXE without uninstalling first and pick the same folder; it replaces
application code and preserves the data folder, including settings, queue,
models, cached downloads and prepared runtimes. If that folder already has
files, Setup asks to update/overwrite it in place. The same version can be
reinstalled. Older versions are rejected.

Upgrading an existing copy (Install or Portable, from any earlier release):
pick its existing application folder (the one containing
auto_subtitle_plus_gui.exe or auto_subtitle_plus.exe). Its data folder stays
in place. Other copies elsewhere are not moved or deleted. An existing
AUTO_SUBTITLE_PLUS_DATA_DIR override continues to take precedence.

Updates are manual. Setup does not launch the app or download dependencies.
Uninstalling an Install-mode setup removes application files but preserves
data and exports; a Portable folder has no uninstaller, so remove it by
deleting the folder yourself. Delete user data yourself only when you no
longer want it.

This release is unsigned. Windows may show a SmartScreen warning; verify the
download and its SHA256 before deciding to run it. Do not disable protection.
