# v0.3.0-rc.7 — Mac release and Windows pipeline alignment

This release rebuilds the Apple Silicon Mac application from the current `main` branch and publishes the Windows x64 artifacts produced by the tagged GitHub Actions pipeline.

## Mac downloads

- `AutoSubtitlePlus-GUI-macOS-arm64.pkg` — recommended installer/update
- `AutoSubtitlePlus-GUI-macOS-arm64.zip` — manual Finder installation
- matching SHA-256 files
- `AutoSubtitlePlus-macOS-NativeSources.tar` and checksum

The Mac build is build 6, ad-hoc signed and not notarized. It requires Apple Silicon and macOS 26+. FFmpeg/ffprobe remain separate prerequisites; settings, model caches and exported files remain outside the app bundle.

## Validation

The release was built and validated locally on Apple Silicon. The Windows artifacts are generated by the tagged Windows workflow, which runs the regression suite and publishes the CLI/GUI ZIPs and checksums.
