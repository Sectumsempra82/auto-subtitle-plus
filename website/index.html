The Mac installer installs or replaces the app in Applications. It bundles Python and processing libraries. Install FFmpeg separately; models download when selected. Processing and translation stay local. CUDA and Hy-MT2 are not available on Mac.

Before your first launch

Internet is needed for the initial dependency and model downloads. Allow several GB of disk space; the small installer or portable ZIP does not include the processing runtime or model weights. Preserve the app’s data folder when upgrading.

CPU is the initial profile. GPU processing requires a compatible NVIDIA driver and the optional Setup CUDA.cmd step.

The v0.3.0-rc.5 executables are unsigned, so Windows may show a SmartScreen warning. See your release’s notes for validation status and known limitations.
